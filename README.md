# Telegram Report Bot

بوت داخلي لتلقي البلاغات من المستخدمين وإرسالها مباشرةً إلى مجموعة دعم داخلية.

## المتطلبات
- حساب GitHub
- حساب على Render أو Heroku
- توكن بوت من BotFather
- ID لمجموعة الدعم الداخلي

## الإعداد
1. انسخ هذا المشروع وارفعه على GitHub.
2. على Render أو Heroku:
   - أنشئ خدمة جديدة (Worker).
   - اربطها مع هذا المستودع.
   - أضف متغيرات البيئة:
     - `BOT_TOKEN` = التوكن من BotFather
     - `SUPPORT_GROUP_ID` = رقم مجموعة الدعم (من @userinfobot)
3. بعد النشر، البوت يشتغل تلقائيًا 24/7.

## الاستخدام
- أرسل /start للبوت
- أرسل نصوص أو صور → ستصل مباشرة لمجموعة الدعم.
